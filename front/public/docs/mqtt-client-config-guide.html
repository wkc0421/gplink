MQTT 客户端接入向导

接入配置 → 创建产品 → 导入设备列表。平台作为客户端连接 Broker，由接入网关按照协议声明的上行 Topic 接收设备消息。

1. 接入配置 · 2. 创建产品 · 3. 导入设备 · 问题排查

第一步：接入配置

先直接选择“新建接入网关”或“选择已有接入网关”，无需展开自定义配置。复用网关时只选择网关，页面显示它绑定的组件和协议；点击“使用已有网关并继续”即可，无需填写接入 ID、Broker 或重新选择协议。

新建网关时输入 2～32 位接入 ID，必须同时包含英文字母和数字，区分大小写。网络组件可直接选择新建或复用；复用组件不需要填写其连接参数。选择已有 MQTT 协议，或者切换到“上传 JAR”上传符合平台规范的协议包。

默认 Broker 为 127.0.0.1:2883。这里的 127.0.0.1 是运行 GpLink 后端的机器，不是浏览器所在的电脑。使用其他 Broker 时展开本步骤顶部的“自定义配置”修改地址和端口。

字段ID 为 abc123 时的默认值
组件名称MQTT客户端_abc123
用户名mqtt_user_abc123
密码mqtt_pwd_abc123（页面中使用密码框）

默认凭据只用于连接，向导不会在 Broker 上创建账号；请预先配置匹配账号。自定义配置允许改用已有账号，匿名连接需同时清空用户名和密码。客户端 ID 在 Broker 上必须唯一。

自定义配置可修改新建资源的名称、凭据、TLS、证书、主题前缀和最大消息长度。已有组件和网关的名称、连接参数不会被改写。TLS 不会自动修改端口，请填写 Broker 实际监听端口；普通订阅的主题前缀留空。

修改接入 ID 时，仍使用默认值的字段会跟随变化，已自定义的值保持不变。“恢复默认”恢复命名和连接默认值。已有协议保持原名称。

点击“保存接入并继续”：注册并检查协议，创建或复用网络组件、接入网关，启动并校验。协议必须支持 MQTT，且至少声明一个带 Topic 的上行 route。

接入 ID 仅用于命名，不会改写协议内部 ID、产品 ID 或设备 ID。保存后的配置显示只读摘要；重新配置可使用“新建接入流程”，已保存的资源会保留。

第二步：创建产品

在步骤顶部直接选择“新建产品”或“选择已有产品”，再填写下方的产品信息。默认新建普通设备产品，名称为 MQTT产品_接入ID；复用已有网关时使用 MQTT产品_网关ID，可以直接修改。产品 ID 可选，留空由系统生成；选择已有产品时，下方显示产品下拉框。

需要属性物模型时，可下载 Excel 或 CSV 模板，填写后上传并点击“导入物模型”。导入会先保存产品及接入绑定，再将属性写入产品；检查表中的属性 ID、名称、地址、排序和精度后继续启用。复用已有产品时，导入会替换该产品的全部属性，并影响其他使用它的设备；不需要物模型时可跳过。

点击“创建产品并继续”后，平台保存产品，绑定第一步的网关和协议，并启用产品。选择已有产品时，继续操作会更新该产品的接入绑定，页面会显示提示。

产品保存完成后才提供设备模板，以便模板包含当前产品标签和协议所需的配置列。若协议要求 Topic 中包含产品 ID，请使用实际保存的产品 ID。

第三步：导入设备列表

  1. 下载 Excel（.xlsx）或 CSV 模板。
  2. 填写设备 ID、设备名称以及协议要求的配置列，保留模板表头；带前导零的设备 ID 按文本填写。
  3. 点击“上传设备列表”。上传文件本身不会创建设备。
  4. 点击“导入并启用”，查看逐行结果、成功与失败数量，下载导入结果与错误详情。

导入使用“仅新增”模式：系统已有 ID（包括其他产品的设备）不会被覆盖；文件内相同 ID 只允许首次有效记录新增，后续重复行失败。其他合法行继续导入。

本步骤顶部的“自定义配置”可关闭“保存后启用设备”，也可改为手动添加单台设备或选择当前产品的已有设备。

若提示旧版接口，页面会显示接口报告的已处理数量和结果文件，但完成状态、仅新增和启用结果仍需核对。请更新匹配的后端版本，并先核对设备列表，避免重复导入已成功的数据。

结果区区分全部成功、部分失败、导入中断和未导入设备。空模板不会显示成功。导入中请保持页面打开；发生中断时不会自动重新发起导入，已成功的数据保留。

重试前先核对设备列表和结果文件，只重新上传失败行。设备 ID 必须与协议从 Topic 或报文中解析出的标识一致。

问题排查与验证

问题处理方式
JAR 上传或加载失败检查上传权限、文件是否为有效平台协议包，以及协议依赖；文件上传成功不等于协议加载成功。
协议不支持 MQTT 或没有上行 routes选择其他协议或修正协议包；可以展开主题预览检查 Topic。
网络组件启动失败检查后端到 Broker 的连通性、端口、匹配账号、TLS 和客户端 ID 冲突。
中途保存失败当前页面保留已创建资源 ID，重试会从失败阶段继续。刷新或关闭页面前记录已创建资源。
导入失败或权限不足按错误行修正必填项、配置和 ID；检查账号对文件、协议、网络组件、网关、产品、设备的操作权限。
导入连接中断已有成功记录保留。先核对实际设备列表，修正网络后仅重传失败或未处理行。

配置和启用成功不代表设备实际在线。最终请让真实设备向 Broker 发送符合协议 Topic、设备 ID 和报文格式的消息，再检查设备上线及属性数据。
