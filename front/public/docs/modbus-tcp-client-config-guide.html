Modbus TCP 客户端配置说明

这份说明面向第一次使用 Modbus TCP 客户端向导的用户。平台会主动连接现场 Modbus 网关，在 TCP 链路上以 Modbus Master 身份读取或写入从机设备。

本页目录 开始前准备 五步配置 保存与测试 常见问题

先理解连接关系

TCP 客户端表示平台主动连接现场设备网关；它描述的是 TCP 连接方向，不改变 Modbus 层的主从角色。平台仍以 Master 发起标准 Modbus RTU 报文，现场设备作为 slave 响应。

  • 已确认现场网关的 IP、TCP 端口和防火墙放行
  • 已确认每台从机的 slaveId，范围通常为 1–247
  • 已准备功能码、寄存器地址、数量、数据类型和字节序
  • 已知道属性 ID、单位、比例和偏移等物模型信息
安全提示：本页截图来自测试环境。生产环境请替换为自己的设备地址和参数，不要把凭据、内网拓扑或敏感地址复制到公开文档。

五步完成配置

1

新建 TCP 客户端接入

在设备管理菜单进入“Modbus 接入向导”，将“配置方式”切换为“新建 TCP 客户端”。填写网络组件和接入网关名称，再填写现场网关的远程主机与远程端口。

页面字段填写规则
网络组件名称用于识别 TCP_CLIENT 网络组件，例如“产线 Modbus TCP 客户端”。
接入网关名称用于识别 Modbus 接入网关，例如“产线 Modbus 网关”。
远程主机/远程端口填写现场网关的 IP 或域名及 TCP 端口；不要填写 modbus:// 等协议前缀。
说明补充现场位置、线路或用途，最多 200 个字符。
TLS（可选）现场网关提供 TLS 时打开开关并选择已有网络证书；普通 Modbus TCP 保持关闭。
负载解析本向导的 Modbus RTU over TCP 使用 DIRECT 解析器，不要把 CRC 当作 TCP 分隔符配置。
2

配置网关产品、网关设备和通讯参数

点击“下一步”进入“网关产品与网关设备”。网关是承载 TCP 会话的父设备，同一条 TCP 连接下的多个 Modbus 从机设备都挂在它下面。

可以选择已有网关产品和设备，也可以分别选择“新建”并填写产品 ID、产品名称、设备 ID、设备名称。再确认响应超时、探测周期和保活超时，这些参数会写入网关产品和从机产品。

3

按产品配置点位、轮询与从机

通过产品列表切换配置组。每组选择或新建一个从机产品，分别维护寄存器映射、物模型、产品轮询和从机列表；点击“添加产品”继续配置其他型号。

每组可单独导入点位 CSV、从机 CSV 或粘贴 Excel 内容。导入仅替换当前组列表。所有产品共用同一条 Modbus 通道，因此 slaveId 在采集器下必须唯一，范围为 1–247。

选择已有采集器会加载其全部产品与从机。已有设备 ID 固定；共享产品的点位与轮询修改会影响其他使用该产品的设备。移除已有从机或整个产品组会列入待解绑清单，保存时只解除与当前采集器的绑定，保留产品、设备和历史数据。

4

确认全部产品并执行测试

核对各产品的点位数、从机数、新增、修改和待解绑内容；分别选择每个产品的测试从机和可读属性。不选择时，默认读取本产品全部可测试从机的第一个可读点位。

点击“保存并测试”统一保存各产品并绑定到同一采集器。TCP 服务端会自动维护完整的 childDeviceIds，无需手动追加第二批设备。新增资源在依赖可用时自动启用；已有停用资源保留原状态，相关测试显示“已跳过”。

测试结果按产品显示“成功”“失败”“等待连接”或“已跳过”。保存成功而采集器未连接时显示等待连接。部分保存失败时请保留页面，修正后重试，向导会复用已创建资源。

保存后如何判断成功

成功标准：网络组件和接入网关启动成功，测试结果中目标从机和属性显示“成功”，并返回实际读取值。

配置保存成功不等于 Modbus 通讯成功；选定点位测试成功也不代表全部点位和轮询计划均已验证。应继续检查其他从机、其他属性和轮询数据。

常见问题

现象优先检查
TCP 连接被拒绝或超时检查远程主机、远程端口、防火墙、路由和现场网关是否监听；确认平台所在节点能访问该地址。
slaveId 无响应确认设备地址在 1–247 范围内且与现场拨码或配置一致；同一链路不要重复使用相同 slaveId。
读取值为空或数值异常逐项核对功能码、地址起点、数量、数据类型、字节序、比例和偏移。设备手册中的 40001 可能对应页面地址 0。
CRC 或拆包错误Modbus RTU over TCP 使用 DIRECT 负载解析；不要把 TCP 连接配置成按 CRC 分隔或混用其他协议解析器。
人工读取成功但轮询没有数据确认产品轮询已启用、采集项包含可读属性、周期和从机覆盖配置正确，并查看设备最新属性时间。
保存中途失败后再次保存异常保留向导页面，根据具体产品和失败阶段修正后重试；已创建资源会复用。刷新页面后可选择已有资源继续配置。
